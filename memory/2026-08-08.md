## LIÇÃO GRANDE: bug de pintura do Chrome 151 (headless E real)
- Sintoma: header (gradiente azul + logo `<img>` + badges) e rodapé deixam de PINTAR (fundo some, fica a cor do body) quando certos conteúdos existem na página.
- Gatilhos confirmados: **qualquer bloco de texto avulso** (ex.: cartão welcome com h1+p entre header e main, ou um div/h1 adicionado no topo do main) + badges+logo no header → header não pinta. Imagem carregada + textos no mesmo elemento do header também quebra.
- Estrutura VERIFICADA que funciona: header = só `img` + badges; nome/tagline fora do header; rodapé só texto (pinta no Chrome real, NÃO pinta no headless — artefato headless-only).
- Headless (`--headless=new --screenshot --disable-gpu --virtual-time-budget`) é NÃO-CONFIÁVEL para verificar esta página: mente sobre header/rodapé. **Sempre verificar no navegador real (browser tool: navigate + screenshot)**.
- ~30 iterações de bisseção (testbed local com python http.server na 8799 + decoder PNG próprio). F4/F5 "funcionavam" por CSS inválido acidental — cuidado com sed que quebra regras CSS.
